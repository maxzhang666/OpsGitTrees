## 独立侧栏

- 文件导航使用脚本自己的独立侧栏，不采用增强 GitHub 原生文件树内部功能的路线。
- 首版固定停靠左侧，不提供左右切换。
- 首次使用默认展开；之后记住用户的收起状态，不在每次进入仓库时重新展开。
- 独立侧栏不等于独立代码阅读器：文件内容仍由 GitHub 原页面展示。
- 侧栏展开时占用页面宽度，为 GitHub 页面挤出空间，不覆盖页面内容；收起时释放占用的空间。
- GitHub 原生文件树保留不动，不自动隐藏、收起或修改其展开状态；是否使用原生树由用户自行决定。
- 两套树同时展开会进一步压缩内容区域，这是保留原生树的空间代价；不通过擅自隐藏原生树解决。
- 已有的收起、调宽和宽度记忆要求继续有效。
- 顶部采用两行紧凑工具栏：第一行是 owner／仓库名与设置按钮，owner 与仓库名分别使用跳转到所有者主页、仓库首页的原生链接；第二行展示当前分支，并放置查找和定位按钮。分支暂时只读展示，不伪装成可用的下拉选择器。移除重复的“返回文件树”常驻图标；打开设置后，同一设置按钮变为明确的关闭按钮，关闭后保留搜索、展开和滚动状态。文件行高 24px，继续使用 SVG 图标和缩进导线；仓库和分支截断时可悬停查看全文。
- 仓库行与分支行之间、分支行与文件树之间各用 1px 通栏分隔线，沿用 GitHub 当前主题边框色；两行各 30px，顶部总高保持 60px，不额外压缩文件内容区。
- 文件树、设置页和 Token 弹窗直接继承 GitHub 当前主题的颜色变量，包括背景、文字、边框、悬停、选中态、目录图标、开关、按钮及弹窗遮罩；切换主题无需刷新。变量缺失时回退到旧版 GitHub 变量或对应明暗默认色，不再使用独立的编辑器配色。
- 按钮、文本输入、下拉框与目录行使用 GitHub 的中等圆角变量，变量缺失时回退到 6px，不再强制使用直角控件。
- 收起按钮位于侧栏底部状态区，不再占用顶部工具栏。当前仍固定左侧；侧栏左右切换和侧栏内切换分支均列入 [Roadmap](roadmap.md)，不在本次实现。
- 按钮、分支和文件树图标统一使用 Lucide SVG，按需打包实际使用的图标；保留按钮的可访问名称和悬停提示，不在页面运行时下载图库。
- 底部品牌名、目录索引状态和收起按钮保持单行，不通过换行挤占目录树高度。窄侧栏内优先保留 `OpsGitTrees`，状态过长时显示省略号，悬停可查看完整状态与错误原因；品牌文字不属于动态状态播报区域。
- 首次加载且尚无可用目录时，树区域整体显示居中的加载图标与提示，并设置 `aria-busy`；已有路径可浏览后立即解除 loading，不阻塞后续后台预加载。失败或空仓库不会保留转圈状态，减少动态效果的系统设置会停用旋转动画。
- 窗口变窄或可用空间不足时，不自动收起侧栏，也不自动切换为覆盖模式；是否收起由用户自行决定。

## 启用范围

- 在 GitHub 仓库首页、目录页和文件页启用侧栏，并跟随当前仓库和版本。
- 首版不在 Issues、PR 等非代码浏览页面显示；离开启用范围时释放侧栏占用的页面空间。

## 点击行为

| 操作 | 已确认行为 |
|---|---|
| 普通点击文件 | 在当前 GitHub 页面加载并展示对应文件，不在脚本内建立另一套代码阅读器 |
| 点击目录 | 箭头、名称和整行均可切换展开／收起状态，不跳转到 GitHub 目录页 |
| Cmd/Ctrl 点击、中键打开文件 | 保留浏览器原有的新标签打开行为，不被普通点击逻辑拦截 |

目录点击决定展示哪些节点，不改变 [默认目录预加载](directory-preloading.md) 策略：不能将“点击展开”实现为主要依靠点击才请求目录数据。

## 搜索展示

- 查找默认只显示顶部图标，点击或使用聚焦查找快捷键后展开输入框；有查询或恢复已有查询时保持展开，不通过隐藏输入框掩盖仍在生效的过滤。
- 在输入框中按 Esc 先清空查询并恢复普通浏览位置；输入已为空时再次按 Esc 收起输入框，焦点返回查找按钮。没有查询时也可再次点击查找图标收起。
- 搜索结果使用过滤树，不切换成独立的扁平结果列表。
- 在全仓库目录索引中按文件名／路径做忽略大小写的子串匹配，不仅匹配当前展开或已渲染的节点；首版不做正则、模糊评分或代码全文搜索。
- 过滤后的展示保留匹配节点及必要的祖先路径，并自动展开祖先目录，让匹配项可见；目录命中时，自动展开止于其祖先路径，不继续展开该目录的子树。
- 目录名称匹配时，保留整个子树供用户点击浏览，但不因搜索自动展开命中目录或其后代；也不强制收起用户已经手动展开的目录。
- 过滤树与普通目录树使用同一份目录索引，不维护另一套远程搜索数据源。
- 索引未完整时，搜索展示也需要说明结果可能不完整；不能将当前未找到解释为整个仓库中不存在。
- 清空搜索后，恢复搜索前的目录展开状态和树的滚动位置，不将搜索期间的临时展开写入普通浏览状态。
- 从过滤树点击文件后，保留查询及过滤状态，便于继续查看其他匹配文件。

## 验收场景

以下为实现后的验收目标，不代表已验证：

- 仓库中出现脚本自己的侧栏，而不是仅在原生文件树上增加按钮或修改其内部行为。
- 缩窄窗口或同时展开两套树后，脚本不因可用空间不足而自动收起侧栏或切换为覆盖模式。
- 展开独立侧栏后，GitHub 页面让出相应宽度而不是被侧栏遮挡；收起后释放该空间。
- 展开或收起独立侧栏，不改变原生文件树的可见性及展开状态。
- 普通点击文件后，GitHub 页面展示对应文件；脚本不额外加载一个自带代码阅读器。
- 点击目录可以展开其内容，GitHub 当前文件内容不因目录展开而切换到目录页。
- 输入文件名／路径后，以过滤树显示结果，并保留能理解其位置的祖先目录。
- 搜索覆盖未展开目录中的索引项；数据尚未完整时有明确提示。
- 搜索时自动展开匹配项的祖先目录；清空查询后，恢复搜索前的展开状态与滚动位置。
- 目录名称命中时，该目录可见，但不会因其后代路径也包含搜索词而自动展开整个子树；用户仍可点击展开查看内容。
- 从过滤树打开文件后，查询和过滤结果保留，不因文件切换退出搜索。

## 设置入口

- 设置页仅保留语言、快捷键开关、简短 Token 状态与账户及“管理 Token”入口。清除 Token、检查已存 Token、检查当前仓库集中在 Token 管理弹窗；检查结果也在弹窗内显示。创建／撤销链接同样保留在弹窗，详细授权说明见文档。
- 语言提供“跟随浏览器 / 简体中文 / English”，默认跟随浏览器；按浏览器偏好顺序选择可用语言，其他语言回退为英文。选择立即生效、全局保存并跨标签同步；切换不重新请求目录，不丢搜索、展开、滚动或 Token 输入。侧栏、弹窗、状态／错误、脚本菜单及可访问名称统一切换；仓库／分支／路径保持原文。
- “管理 Token”打开当前页面内的模态弹窗，不打开浏览器窗口／标签，不使用原生 `alert`／`prompt`。打开时回填已存 Token，默认密码遮罩，输入框右侧眼睛按钮切换明文／遮罩。支持右上角关闭、Esc 和点击遮罩，关闭时清空输入并取消未完成验证或仓库检查；重开恢复遮罩，晚到检查不能更新新的弹窗。侧栏和管理器菜单只打开管理弹窗，不提供直接清除；共享 DOM 的安全边界及失败语义见 [仓库授权](authentication.md)。
- Token 弹窗标题为“Token 管理”，保存状态与账户合并为一行；宽度上限 440px，小屏自动收窄，操作按钮允许换行。去掉品牌副标题、介绍和自动回填说明；权限与安全边界各用短句，不在空闲时显示“就绪”提示。检查、保存、失败及取消结果仍即时显示。
